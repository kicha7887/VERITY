## 📌 Executive Summary

Modern large language models frequently hallucinate facts, invent statistics, and cite non-existent sources when analyzing dense technical documentation. In high-stakes domains—such as public policy, governance, compliance, and scientific audits—answers without verifiable citations cannot be trusted.

**VERITY** is an evidence-first, multimodal Retrieval-Augmented Generation (RAG) platform designed specifically for government publications, policy briefs, and statistical reports. Every answer generated by VERITY is deterministically verified against original source text, tables, and charts. If an answer cannot be verified with mathematical and lexical certainty, VERITY explicitly **refuses** to answer rather than speculating.

## 🚀 Key Highlights & Capabilities

- **Strict Deterministic Verification (No LLM Self-Grading)**:
  Unlike systems that ask an LLM to "grade its own homework", VERITY employs algorithmic verification:
  - **Numerical Exactness**: Every number, percentage, or currency figure in a claim must appear verbatim in the cited passage or be tagged as an image-derived visual estimate.
  - **Lexical Overlap**: Claims must satisfy Jaccard and n-gram overlap thresholds against the cited passage.
  - **Grounding Validation**: Every citation must map to an existing, verified passage on the exact cited page. Claims failing validation are automatically pruned.
- **True Multimodal Understanding**:
  - **Text Layer**: Extracted cleanly with paragraph boundaries using PyMuPDF.
  - **Structured Tables**: Converted to clean Markdown representations using `pdfplumber` while preserving row and column relationships.
  - **Visual Elements & Charts**: Detected through vector drawings and embedded rasters; analyzed visually via Gemini vision for charts and trend lines.
  - **OCR Fallback**: Automatically activates Tesseract OCR for scanned documents lacking a native digital text layer.
- **Interactive Visual Evidence Inspection**:
  - Users can click **🔍 Inspect original page** on any citation to view the actual rendered PDF page with the cited evidence highlighted with a golden overlay.
- **Multi-Document & Comparative Reasoning**:
  - Upload multiple PDFs simultaneously; filter and toggle specific documents per question. Cross-document citations clearly identify filename, page, and extraction methodology.
- **Executive Dark & Light Theming**:
  - Out of the box support for custom corporate styling, including a dark roast mocha theme with caramel accents.
- **Multi-View Analytics Dashboard**:
  - **Chat View**: Conversational interface with citation tags, interactive page inspection, and feedback tracking.
  - **Insights View**: Document metadata, extracted statistics (percentages/figures), n-gram term frequencies (Plotly), and interactive table viewers.
  - **Evaluation View**: Real-time display of measured benchmark metrics from automated test suites.

## ⚡ Quick Start Guide

### 1. Prerequisites
- **Python 3.10+**
- (Optional) **Tesseract OCR** binary:
  - **Ubuntu / Debian**: `sudo apt install tesseract-ocr`
  - **macOS**: `brew install tesseract`
  - **Windows**: Install via [UB-Mannheim Tesseract installer](https://github.com/UB-Mannheim/tesseract/wiki) and set `TESSERACT_CMD` in `.env` if not in PATH.

### 2. Clone and Setup Environment

```bash
# Clone the repository
git clone https://github.com/kicha7887/VERITY.git
cd VERITY

# Create and activate a virtual environment
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Open `.env` and set your Google Gemini API key:
```ini
GEMINI_API_KEY=your_actual_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
```

> **Note**: If `GEMINI_API_KEY` is omitted, VERITY automatically operates in **Retrieval-Only Mode**, displaying retrieved document passages with full citation data without calling an LLM.

### 4. Run the Application

```bash
streamlit run app.py
```

The application will start immediately at `http://localhost:8501`.

## 📊 Benchmark Evaluation

Run the objective evaluation framework against the benchmark question set:

```bash
python -m evaluation.evaluate
```

This benchmark evaluates:
1. **Retrieval Hit Rate**: Percentage of questions where the ground-truth page was retrieved in the top-k results.
2. **Citation Correctness**: Percentage of claims that accurately cite the verified page.
3. **Faithfulness / Verification Rate**: Percentage of generated claims that pass deterministic numerical and lexical verification.
4. **Refusal Accuracy**: Whether the system correctly refused to answer when information was absent from the document.
5. **Retrieval Latency**: Measured search time per query.

Results are written directly to `evaluation/results.json` and rendered in the **Evaluation** tab inside the Streamlit UI.

## 🛡️ Security, Privacy & Session Isolation

- **Client Session Isolation**: Each session generates a cryptographically secure random session ID (`uuid4`). Uploaded documents, vector indexes, and extracted text are stored in dedicated directories (`data/uploads/<sid>/`, `data/indexes/<sid>/`).
- **Data Pruning**: Files are retained in memory/disk for the active browser session and purged upon conversation deletion or after 24 hours.
- **Prompt Injection Defense**: All document content (text and images) is wrapped inside structured `<evidence>` delimiters and treated strictly as untrusted data in the system instructions.
- **Deterministic Bounds**: Generation parameters enforce low temperature (`0.1`) and structured JSON schema outputs to minimize variance and hallucinations.

## 🎬 5-Minute Demo Walkthrough

1. **Upload**: Drop any government or financial PDF report (e.g., Annual Budget, NITI Aayog Report, Health Survey).
2. **Observe Ingestion**: Watch the progress bar as the document parses text, extracts tables into structured markdown, and builds local vector embeddings.
3. **Ask an Overview Question**: Ask *"What is this document about?"* to receive an overview grounded across sampled pages.
4. **Inspect Original Page**: Click the **🔍 Inspect original page** button on any citation to see the original page with the exact cited evidence highlighted in gold.
5. **Query a Table**: Ask a question requiring tabular statistics (e.g., *"What was the budget allocation in 2023?"*). VERITY retrieves the structured table row and provides exact figures.
6. **Query a Visual Chart**: Ask *"What trend is shown in the chart on page X?"*. VERITY sends the rendered page image to Gemini Vision to describe the visual trends.
7. **Test Refusal**: Ask a question whose answer does not exist in the PDF (e.g., *"What is the capital of Mars?"*). VERITY will state: *"I couldn't find sufficient evidence in the uploaded documents to answer this question reliably."*
8. **Inspect Insights & Evaluation**: Switch to the **Insights** view to inspect document metrics, term frequencies, and tables, or open **Evaluation** to view benchmark scores.
